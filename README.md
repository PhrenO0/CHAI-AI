# 청호나이스 브랜드 커뮤니케이션 전략 제안 (오준상 · 이민욱)

핵심 메시지는 **"차별적인 홈카페 경험"**. 홈카페를 경험하고 싶어 하는 독립 2030에게, 정수·얼음·커피를 한 번에 해결하는 에스프레카페와 펭귄 캐릭터로 다가가는 전략 제안. HTML 슬라이드(16:9) 덱.

## 보기

`index.html`을 브라우저로 연다. 뷰포트 폭에 맞춰 자동으로 맞춰진다.

## PDF로 내보내기

브라우저 인쇄(⌘/Ctrl+P) → 대상 "PDF로 저장", 용지 가로, 배경 그래픽 켜기. 슬라이드당 1페이지로 떨어진다.

## 직접 수정하기 (편집 모드)

오른쪽 위 툴바에서 켠다.

- **수정 모드**: 켜면 제목·본문·데이터 등 텍스트 블록에 점선 테두리가 생긴다. 클릭하면 바로 그 자리에서 타이핑해 고칠 수 있다(일반 문서 편집과 동일). 제목에서 Enter는 줄바꿈으로 처리된다.
- **강조(파랑)**: 수정 모드에서 텍스트를 드래그로 선택하고 툴바의 "강조"를 누르면 그 부분이 파란 강조색이 된다. 이미 강조된 부분을 선택하고 다시 누르면 해제된다. HTML을 직접 건드릴 필요 없이 제목 강조를 바꿀 수 있다.
- **초안 표시**: `초안 · 문구 교체` 같은 노란 태그가 붙은 문구는 내가 임시로 채운 초안이니 실제 문구로 교체하면 된다.
- **이미지 업로드**: `[ ... ]` 라벨이 붙은 회색 사선 프레임을 클릭하거나 이미지 파일을 끌어다 놓으면 그 자리에 바로 들어간다. 프레임에 마우스를 올리면 우측 상단에 × 버튼이 떠서 원래 플레이스홀더로 되돌릴 수 있다.
- **자동 저장**: 수정 내용은 0.6초 후 이 브라우저의 로컬 저장소에 자동 저장된다. 새로고침해도 유지된다. 단, 저장 위치는 이 브라우저·이 파일 경로에 한정되며 다른 사람과 공유되지 않는다.
- **내보내기**: 지금까지의 수정을 반영한 완성된 HTML 파일을 다운로드한다. `styles/deck.css`를 그대로 참조하므로, 내보낸 파일은 이 저장소의 `styles` 폴더와 같은 위치에 두고 열어야 스타일이 유지된다.
- **초기화**: 로컬 저장소의 수정 내용을 지우고 원본으로 되돌린다.

## 구성

- `index.html` — 덱 본체. 표지 + 5개 Part 디바이더 + 본문 슬라이드(약 23장).
- `styles/deck.css` — 디자인 시스템(토큰·컴포넌트·인쇄 CSS).
- `DESIGN.md` — 디자인 시스템 문서.
- `HUMANIZE.md` — 카피 편집 규칙(AI 티 줄이기 + 데이터 무결성).
- `PPTX-PLAYBOOK.md` — 편집 가능한 한글 PPTX 제작 노하우(좌표계·폰트 임베딩·QA 자동화·이미지 수집·장표 설계).
- `assets/img/` — 덱에 쓰인 이미지.

본문 서사: Part 1 과제 정의(2030 생애가치·재해석) → Part 2 브랜드 진단(경쟁 카피·현재 커뮤니케이션) → Part 3 브랜드 전략(홈카페 독립 2030·근거·차별적 홈카페 경험) → Part 4 캠페인 전략(펭귄 광고·팝업) → Part 5 검증 및 기대효과.

경쟁사명은 비교 목적상 익명 처리(코OO·SKOO·쿠OO·LGOO), 모델명은 제외한다.

## 콘텐츠·이미지 교체

- 이미지: `[ ... ]` 라벨이 붙은 `.imgframe`은 플레이스홀더다. 실제 제품·펭귄·경쟁사 광고·페르소나·목업 이미지로 교체한다.
- 숫자: `출처 확인 예정`·`조사 후 반영` 표기가 있는 값은 공식 자료/조사 결과로 확정 후 넣는다.
- 70페이지 근거 자료는 본문이 아니라 Evidence Library(부록)로 둔다.

## 데이터 주의

"세계 최초"·판매량·재인용 수치·근거 내 불일치(팝업 증가율 79%↑ vs 109%↑)는 원 출처 확인 전까지 본문에서 빼거나 "출처 확인 예정"으로 둔다. 자세한 규칙은 `HUMANIZE.md`.

## 공유용 디자인 템플릿

`deck-template/` — 이 프로젝트의 디자인 시스템과 제작 툴체인만 떼어낸 **재사용 템플릿**이다.
내용은 전부 가상의 브랜드 예시로 바꿨으므로 그대로 외부에 공유해도 된다.
`deck-template/README.md`부터 읽으면 된다. (제작 노하우는 `deck-template/PLAYBOOK.md`)
